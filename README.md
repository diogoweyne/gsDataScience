# 🚀 GS Data Science — Análise da Frota de Satélites Operacionais

Projeto desenvolvido para a Global Solution 2026 da FIAP com foco em Data Science, Estatística Descritiva e Visualização de Dados.

## 📖 Sobre o Projeto

Este projeto realiza uma análise exploratória da frota mundial de satélites operacionais utilizando dados do UCS Satellite Database.

A proposta é aplicar conceitos de Ciência de Dados para identificar padrões relacionados à massa dos satélites, vida útil, ano de lançamento, tipos de órbita e distribuição geográfica dos operadores.

---

## 📈 Principais Insights

- A massa dos satélites apresenta forte assimetria positiva.
- A órbita LEO concentra a maior parte dos satélites operacionais.
- Os Estados Unidos lideram a operação de satélites no mundo.
- Houve forte crescimento dos lançamentos após 2015.
- Satélites mais pesados tendem a possuir maior vida útil.
